# Triage Labels

Map canonical skill roles to these tracker labels.

| Role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified and ready for autonomous implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill names a role, use its corresponding tracker label.
Edit the tracker-label column when the repository’s vocabulary changes.
